# DELIES — веб-версия (HTML/CSS/JavaScript)

Полноценное одностраничное приложение без сборки и без внешних CDN.
Все данные хранятся **локально на устройстве** (IndexedDB, при недоступности —
localStorage). Сетевых запросов приложение не выполняет.

## Запуск

Приложение использует ES-модули, поэтому его нужно открывать через HTTP-сервер,
а не через `file://`.

### Вариант 1 — встроенный сервер репозитория (Node.js ≥ 18)

```bash
cd DELIES
npm run serve          # http://localhost:8080
```

### Вариант 2 — Python

```bash
cd DELIES/main
python3 -m http.server 8080
# открыть http://localhost:8080/
```

### Вариант 3 — любой статический сервер

Любой сервер, отдающий файлы из каталога `main/` (nginx, `npx serve`, Apache).
Корень сайта — каталог `main/`, точка входа — `index.html`.

## Возможности

- **Главная** — приветствие, дата и часы, прогресс дня, события и задачи на сегодня,
  ближайшие напоминания, быстрые действия, статистика.
- **Календарь** — месяц / неделя / день, создание, изменение и удаление событий,
  повторяющиеся события, категории и цветовые метки, задачи по дням.
- **Задачи** — приоритеты, сроки, подзадачи, категории, поиск, фильтры, сортировка,
  статусы выполнения, группировка (просроченные / сегодня / завтра / позже).
- **Напоминания** — дата и время, повторение, включение/выключение, история срабатываний.
- **Заметки** — поиск, закрепление, цветовые метки, категории.
- **Покупки** — списки, товары, количество, отметка купленного, прогресс, категории.
- **Статистика** — метрики, график за 7 дней, активность за 30 дней, срезы по категориям
  и приоритетам, история выполнения.
- **Настройки** — тема (светлая/тёмная/системная), язык (ru/uk/en), начало недели,
  уведомления, экспорт/импорт/сброс данных, управление категориями, о приложении.

## Хранение и переносимость данных

- Основное хранилище — **IndexedDB** (`delies`), резервное — `localStorage`
  (`delies.v1.*`), крайний случай — память (с предупреждением в интерфейсе).
- Экспорт создаёт JSON-файл `delies-backup-YYYYMMDD-HHmm.json`; импорт проверяет
  формат, схему и каждую запись, затем заменяет данные.
- Данные не покидают устройство: ни аналитики, ни трекеров, ни внешних CDN.

## Ограничения веб-версии

- Напоминания срабатывают, пока вкладка с DELIES открыта (используется Notification API).
  Фоновые системные уведомления доступны только в Android-приложении — это явно
  указано в разделе «Напоминания».
- Синхронизация между устройствами не поддерживается: серверной части нет.

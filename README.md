# DELIES

**DELIES** — универсальный персональный помощник для организации повседневной жизни:
календарь, задачи, напоминания, заметки, списки покупок и статистика.
Один продукт — две рабочие версии: **веб-приложение** и **Android-приложение (APK)**.

- Материальный дизайн 3 (Material Design 3): графитовый фон, фиолетовые акценты,
  светлая и тёмная темы, удобное управление одной рукой.
- Интерфейс на русском языке; украинская и английская локализации включены.
- Все данные — только на устройстве. Нет аккаунтов, рекламы, трекеров и сетевых запросов.
- Веб-версия работает offline (без обязательного интернета), Android — с настоящими
  системными уведомлениями через `AlarmManager` и `NotificationManager`.

## Структура репозитория

```
DELIES/
├── main/                  # DELIES WEB — готовое HTML-приложение (index.html, css, js, assets)
├── android/               # DELIES ANDROID — самостоятельный проект Kotlin/Gradle
├── docs/
│   ├── ARCHITECTURE.md    # архитектура, модель данных, мост JS ↔ Kotlin, безопасность
│   ├── FEATURES.md        # матрица функций по платформам
│   └── TESTING.md         # что реально протестировано и как повторить
├── tests/                 # автотесты веб-версии (jsdom) и локальный статический сервер
├── .github/workflows/
│   └── android-build.yml  # сборка APK + прогон тестов, артефакт DELIES-Android-APK
├── package.json           # только тестовый инструментарий (не часть продукта)
├── LICENSE                # MIT
└── README.md
```

Исходники HTML и Android **не смешаны**: `main/` — самостоятельное веб-приложение,
`android/` — самостоятельный Android-проект. При сборке APK каталог `main/`
копируется в assets, поэтому интерфейс и логика в обеих версиях одинаковые.

## Быстрый старт: веб-версия

Нужен любой статический HTTP-сервер (ES-модули не работают через `file://`):

```bash
# вариант 1 — встроенный сервер
npm run serve                 # http://localhost:8080

# вариант 2 — python
cd main && python3 -m http.server 8080
```

Подробнее: [`main/README.md`](main/README.md).

## Быстрый старт: Android

```bash
cd android
./gradlew assembleDebug       # нужен JDK 17 и Android SDK 34
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Готовый APK также собирается в GitHub Actions:
**Actions → Android build → Run workflow**, затем скачать артефакт
`DELIES-Android-APK`. Подробнее: [`android/README.md`](android/README.md).

## Данные и приватность

- Основное хранилище — IndexedDB; резервное — localStorage; при недоступности обоих
  интерфейс честно сообщает, что данные не сохранятся.
- Экспорт/импорт — JSON-файл, импорт проверяет формат и каждую запись.
- Приложение не выполняет сетевых запросов: в веб-версии нет `fetch`/XHR, в
  Android-манифесте нет разрешения `INTERNET`.
- Синхронизации между устройствами нет: серверной части не существует. Перенос —
  вручную через экспорт/импорт.

## Тестирование

```bash
npm ci && npm test        # 35 автотестов веб-версии
cd android && ./gradlew testDebugUnitTest   # юнит-тесты планировщика и валидации
```

Те же проверки выполняются в GitHub Actions при каждом push. Результаты и список
того, что **не** проверялось (эмулятор, физическое устройство), — в
[`docs/TESTING.md`](docs/TESTING.md).

## Сборка APK в CI

Workflow `.github/workflows/android-build.yml`:

1. прогоняет тесты веб-версии (`npm ci && npm test`);
2. ставит JDK 17 и Android SDK 34;
3. запускает юнит-тесты Android и lint;
4. собирает `assembleDebug`, проверяет наличие и размер APK;
5. загружает артефакт **`DELIES-Android-APK`** и отчёты тестов.

Автоматические релизы не публикуются — публикация остаётся за владельцем проекта.

| Возможность | Статус |
| --- | --- |

| Восстановление после падения render-процесса | ✔ `onRenderProcessGone` |

| Безопасный JS-мост | ✔ один метод, белый список, проверка origin |

## Явно не реализовано

- Синхронизация между устройствами и любая серверная часть (нет сервера — нет обещаний).
- Push-уведомления из сети, аккаунты, реклама, аналитика — отсутствуют намеренно.
- Повторения с исключениями дат («кроме 9 мая») — не поддерживаются.
- Виджеты рабочего стола, Wear OS, iOS — вне рамок проекта.
- Публикация Release и Play Store — по решению владельца проекта.
